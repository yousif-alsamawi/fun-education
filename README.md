# 📖 منصة ومستودع مجلات وقصص الأطفال التربوية المخصصة (مكتبة الشعلة)
### Personalized Children's Educational Magazine & Booklet Platform

مشروع متكامل صُمم خصيصاً لمكتبة جامعية لتوسيع مصادر الدخل على مدار العام؛ من خلال تحويل المشاكل السلوكية للأطفال (مثل: إهمال المذاكرة، الكذب، العناد، التنمر، إدمان الأجهزة) إلى **مجلات وقصص مصورة مخصصة** يظهر فيها الطفل كبطل بجانب شخصيته الكرتونية أو بطله الخارق المفضل بملامح وجه مطابقة، مع صفحات تلوين تفاعلية وشهادة بطل معتمدة، جاهزة للطباعة والتدبيس المباشر في المكتبة.

---

## 🏗️ هيكلية المستودع الموحد (Monorepo Structure)

```text
├── apps/
│   ├── web/                     # لوحة تحكم موظف المكتبة (Next.js / HTML Dashboard + Server)
│   │   ├── public/index.html    # الواجهة التفاعلية العربية بالكامل
│   │   └── server.js            # خادم التشغيل وتوليد ملفات الطباعة
│   └── flow-agent/              # وكيل متصفح ومساعد التكامل مع Google Flow
│       └── src/copilot.ts       # محول أوامر التوليد السريعة
│
├── packages/
│   ├── core/                    # النماذج المشتركة وحسابات ملازم التدبيس الرياضية
│   │   ├── src/types.ts         # تعريفات الطفل، القصة، المشاهد، المجلات
│   │   ├── src/constants.ts     # السلوكيات الجاهزة، الأساليب الفنية، الأبطال
│   │   └── src/imposition.ts    # خوارزمية ترتيب الصفحات للتدبيس النصفي (Saddle Stitch)
│   │
│   ├── pdf-engine/              # محرك إخراج وتصدير المجلات عالي الدقة (300 DPI)
│   │   ├── src/templates/       # قوالب نسخة القراءة ونسخة الملازم المزدوجة
│   │   └── src/index.ts         # دوال التصدير والطباعة
│   │
│   └── skills/                  # مهارات الذكاء الاصطناعي لوكلاء Antigravity و OpenCode
│       ├── story-pedagogue/     # مهارة الكاتب التربوي وحبكة التعزيز الإيجابي
│       ├── flow-art-director/   # مهارة المخرج الفني وأوامر Google Flow وثبات الوجه
│       ├── coloring-page-creator/# مهارة توليد صفحات التلوين المفرغة (3+ صفحات)
│       └── booklet-typesetter/  # مهارة الإخراج والتنسيق والخطوط العربية
│
├── pnpm-workspace.yaml          # ضبط مساحات العمل
├── turbo.json                   # تنسيق مهام البناء والتطوير
└── package.json                 # التبعات الرئيسية
```

لوحة التحكم مجهزة لتعمل فوراً دون أي تعقيدات برمجية:

```powershell

```

ثم افتح المتصفح على الرابط:

## 🖨️ دليل الطباعة والتدبيس في المكتبة (Booklet Imposition Guide)

تمت برمجة محرك الـ PDF بحيث يقوم بترتيب الصفحات تلقائياً بنظام **الملازم (Saddle-Stitch Imposition)** لتوفير الورق وسرعة التدبيس:

1. اضغط على زر **"طباعة نسخة الملازم المزدوجة"** في لوحة التحكم.
2. في إعدادات الطابعة:
   - مقاس الورق: **A4**.
   - الاتجاه: **أفقي (Landscape)**.
   - نوع الطباعة: **على الوجهين (Duplex) - الالتفاف على الحافة القصيرة (Flip on short edge)**.
3. النتيجة: ستخرج الطابعة **3 أوراق A4 فقط**، كل ورقة مطبوعة من الوجهين:
   - **الورقة 1**: الوجه الأمامي (صفحة 12 + 1) | الوجه الخلفي (صفحة 2 + 11).
   - **الورقة 2**: الوجه الأمامي (صفحة 10 + 3) | الوجه الخلفي (صفحة 4 + 9).
   - **الورقة 3**: الوجه الأمامي (صفحة 8 + 5) | الوجه الخلفي (صفحة 6 + 7).
4. **التدبيس**: اجمع الأوراق الثلاث فوق بعضها، اطوِها من المنتصف، وضع دبوسين في خط المنتصف تماماً؛ لتصبح بين يديك مجلة أطفال حقيقية مقاس A5 في دقيقة واحدة!

## 🤖 مهارات الذكاء الاصطناعي (AI Skills for OpenCode / Antigravity)

إذا كنت تستخدم وكلاء مثل Antigravity أو موديلات مجانية في OpenCode (مثل Nemotron Ultra أو Gemini Flash):
- تم تزويد مجلد `packages/skills` بالمهارات التالية:
  - `story-pedagogue`: لصياغة القصة التربوية والحوارات المشكولة بدون وعظ مباشر.
  - `flow-art-director`: لصياغة أوامر Google Flow بدقة لضمان ثبات الملامح والأسلوب الفني.
  - `coloring-page-creator`: لإنتاج صفحات التلوين الثلاث بجودة خطوط عريضة مفرغة.
  - `booklet-typesetter`: لقواعد الهوامش والخطوط والشهادة المعتمدة.
